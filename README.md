# AI-Web-Scraper

An AI-powered web scraper built with Python, Selenium, BeautifulSoup, LangChain, Streamlit, and Ollama

# Features

•Web Scraping: Automatically scrapes content from websites using Selenium and BeautifulSoup.

•AI-Powered Parsing: Uses LangChain and LLMs (e.g., LLaMA via Ollama) to extract specific information from raw HTML or text content.

•Customizable Scraping: Easily define what data to extract through natural language prompts.

•Real-Time Interaction: Interact with the tool via a simple and responsive Streamlit web interface.
